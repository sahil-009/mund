🚀 QUICK START GUIDE

LOCATION
  Project: /home/sahil/Desktop/mund/

TO RUN
  $ cd /home/sahil/Desktop/mund
  $ npm start

THEN
  • Press Ctrl+O to open a file
  • Press F5 to run code
  • See output in terminal
  • Use Ctrl+Shift+P for all commands

TO TEST
  1. npm start
  2. Ctrl+O → Select test/example.cpp
  3. F5 → Compile & run
  4. Terminal shows "Sum: 60" ✓

TO BUILD PACKAGES
  $ npm run build          # Production bundle
  $ npm run dist:deb       # Debian package
  $ npm run dist:appimage  # AppImage
  $ npm run dist:all       # Both formats
